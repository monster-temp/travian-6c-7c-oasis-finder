# Contributing

Thanks for helping improve the finder.

1. Do not include real authentication cookies, player details, private server data, or generated scan reports.
2. Keep the default server and coordinates generic.
3. Run `bun run check` and `bun run build` before submitting a change.
4. Confirm that `build/main.js` matches the TypeScript source.
5. Explain behavioral changes and their effect on request volume in the pull request.

Please use synthetic coordinates and redacted examples in bug reports.
